## Правки и изменения

### Переработка работы с монтажным профилем (2024)

**Требования:**
- В файле Build.xlsx указана Услуга (столбец "Спецификация") и комплектующие
- Если услуга не указана, комплектующие относятся к предыдущей услуге
- Рядом указано изначально количество, которое потом умножается (по площади, периметру, количество дополнительных элементов)
- Нужно привести структуру данных к нужному виду
- Добавить экспорт и импорт из Excel

**Реализовано:**
1. Добавлена библиотека `xlsx` для работы с Excel файлами
2. Обновлена структура данных `Material` - добавлено поле `initialQuantity` (изначальное количество из Excel)
3. Создан сервис `excelService.ts` с функциями:
   - `importProfileFromExcel` - импорт профиля из Excel
   - `exportProfileToExcel` - экспорт профиля в Excel
4. Обновлена логика расчета сметы - используется `initialQuantity` если оно указано
5. Добавлен UI для импорта/экспорта в `ProfilesList.tsx`:
   - Кнопка "Импорт Excel" с диалогом выбора файла
   - Кнопка "Экспорт Excel" для скачивания профиля

**Структура Excel файла:**
- Столбец "Спецификация" - услуга (Work)
- Столбец "Комплектующие" - материалы (Material)
- Столбец "Количество" - изначальное количество
- Столбец "Ед.изм" - единица измерения
- Столбец "Цена" - цена
- Столбец "Тип расчета" - byArea/byPerimeter/byCount
- Столбец "Коэффициент" - коэффициент умножения

**Логика импорта:**
- Если указана "Спецификация" - создается новая работа (Work)
- Если "Спецификация" пуста - комплектующие относятся к предыдущей услуге
- Изначальное количество сохраняется в `Material.initialQuantity`
- При расчете сметы используется `initialQuantity` если оно указано, иначе `WorkMaterial.quantity`
