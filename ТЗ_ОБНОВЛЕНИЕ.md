2.4. Монтажный профиль организации (Installation Profile)

Каждый пользователь может настроить собственный профиль монтажа — набор материалов и работ.
Профиль привязан к пользователю и синхронизируется между устройствами.

Структура профиля:

2.4.1. Материалы (Materials)

Материалы — это расходные ресурсы, которые используются при выполнении работ.

Каждый материал:

id (уникальный идентификатор)

name (наименование материала, например: "Полотно потолка", "Багет", "Расходники")

unit (единица измерения: м², м.п., шт)

price (стоимость за единицу измерения)

calculationType (тип расчёта количества):
- byArea (по площади помещения)
- byPerimeter (по периметру помещения)
- byCount (по количеству элементов)

coefficient (коэффициент, опционально, для корректировки расчёта)

Примеры материалов:
- Полотно потолка (м², расчёт по площади)
- Багет (м.п., расчёт по периметру)
- Светильники (шт, расчёт по количеству)
- Расходники (м², расчёт по площади с коэффициентом)
- Крепёж (шт, расчёт по количеству элементов)

2.4.2. Работы (Works)

Работы — это виды деятельности, которые выполняются при монтаже. Каждая работа имеет свою стоимость и требует определённые материалы.

Каждая работа:

id (уникальный идентификатор)

name (наименование работы, например: "Монтаж потолка", "Установка светильников")

unit (единица измерения: м², м.п., шт)

workPrice (стоимость работы за единицу измерения)

calculationType (тип расчёта объёма работ):
- byArea (по площади помещения)
- byPerimeter (по периметру помещения)
- byCount (по количеству элементов)

requiredMaterials (массив требуемых материалов для этой работы):
- materialId (ссылка на материал)
- quantity (количество материала на единицу работы, опционально, по умолчанию 1)
- calculationOverride (опционально, переопределение типа расчёта для этого материала в контексте работы)

Примеры работ:

1. Монтаж потолка (м², расчёт по площади):
   - workPrice: стоимость работы за м²
   - requiredMaterials:
     - Полотно потолка (quantity: 1, расчёт по площади)
     - Расходники (quantity: 0.1, расчёт по площади)

2. Установка багета (м.п., расчёт по периметру):
   - workPrice: стоимость работы за м.п.
   - requiredMaterials:
     - Багет (quantity: 1, расчёт по периметру)
     - Крепёж (quantity: 4, расчёт по количеству точек крепления)

3. Установка светильников (шт, расчёт по количеству):
   - workPrice: стоимость работы за штуку
   - requiredMaterials:
     - Светильники (quantity: 1, расчёт по количеству)
     - Расходники (quantity: 0.05, расчёт по площади для каждого светильника)

Логика расчёта сметы:

1. Для каждой работы определяется объём (по площади/периметру/количеству)
2. Рассчитывается стоимость работы: объём × workPrice
3. Для каждого требуемого материала работы:
   - Определяется количество материала (по площади/периметру/количеству с учётом quantity)
   - Рассчитывается стоимость материала: количество × materialPrice
4. Итоговая стоимость работы = стоимость работы + сумма стоимости всех требуемых материалов

Профиль хранится в IndexedDB локально и синхронизируется с backend.

4. Смета (Estimate Engine)

Смета должна формироваться автоматически, используя:

Площадь помещения

Периметр помещения

Число дополнительных элементов (светильники и др.)

Монтажный профиль (работы с их материалами)

Алгоритм расчёта сметы:

1. Для каждой работы из профиля монтажа:

   a. Определение объёма работы:
      - Если calculationType = byArea: объём = площадь помещения
      - Если calculationType = byPerimeter: объём = периметр помещения
      - Если calculationType = byCount: объём = количество элементов (светильники, вырезы и т.д.)

   b. Расчёт стоимости работы:
      стоимостьРаботы = объём × workPrice

   c. Для каждого требуемого материала (requiredMaterials):

      - Определение количества материала:
        * Если calculationType материала = byArea: количество = площадь × quantity × coefficient
        * Если calculationType материала = byPerimeter: количество = периметр × quantity × coefficient
        * Если calculationType материала = byCount: количество = количество элементов × quantity × coefficient
        * Если указан calculationOverride в requiredMaterials, использовать его вместо calculationType материала

      - Расчёт стоимости материала:
        стоимостьМатериала = количество × materialPrice

   d. Итоговая стоимость работы:
      итоговаяСтоимостьРаботы = стоимостьРаботы + сумма(стоимостьМатериала для всех requiredMaterials)

2. Формирование позиций сметы:

   Для каждой работы создаётся позиция сметы:
   - Наименование работы
   - Единица измерения
   - Количество (объём работы)
   - Цена работы
   - Сумма работы

   Для каждого материала работы создаётся подпозиция:
   - Наименование материала (с отступом, как подпункт работы)
   - Единица измерения материала
   - Количество материала
   - Цена материала
   - Сумма материала

3. Итоговая сумма:
   итоговаяСумма = сумма(итоговаяСтоимостьРаботы для всех работ)

Структура результата (EstimateItem):

- workId (ID работы)
- workName (наименование работы)
- workUnit (единица измерения работы)
- workQuantity (количество/объём работы)
- workPrice (цена работы за единицу)
- workTotal (стоимость работы)
- materials[] (массив материалов):
  - materialId
  - materialName
  - materialUnit
  - materialQuantity
  - materialPrice
  - materialTotal
- workTotalWithMaterials (стоимость работы + все материалы)

Передать данные в модуль PDF для генерации документа.
